Installation
============

.. code-block:: bash

   pip install tensor-ring-decomposition

Requires PyTorch 2.0+, opt_einsum 3.3+, and safetensors 0.4+.

Optional dependencies
---------------------

.. code-block:: bash

   # For HuggingFace integration
   pip install tensor-ring-decomposition[hf]

   # For GGUF format support
   pip install tensor-ring-decomposition[gguf]

   # Everything
   pip install tensor-ring-decomposition[all]

   # Development
   pip install tensor-ring-decomposition[dev]
